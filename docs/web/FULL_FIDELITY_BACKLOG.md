# Nordicandia 网页版完整复刻任务清单

日期：2026-10-03。核对代码基线：`acec2a6`。目标是复现约定原版版本的可观察行为、内容和表现。
这是完整复刻的后续清单；M0–M3 已完成的原型交付保留，不代表对应系统达到原版一致。
本次只整理任务及验收要求，未重新执行游戏验收，也未修改运行时代码。

## 完成的定义

每个条目分别记录：**原版证据、已提取数据、运行时接入、原版对照结果**。
有方法名、参数表或通过网页 smoke，不能单独作为行为一致的证据。
推荐状态：未核对 → 已定位 → 已还原 → 已接入 → 对照通过；有近似时注明具体差异。

固定输入可控制的规则，比较完整结果和事件顺序；浮点/时间误差逐项约定。
无法控制原版随机种子的规则，比较条件分布、边界和置信区间，不要求跨引擎逐次抽签相同。
画面/操作使用同场景录像与截图核对；每个差异必须关闭或获得明确的范围豁免。
先建立内容分母，再报告“多少项已验收/多少项应有”，不继续使用无依据的 35–45% 总完成度。

优先级：P0 为证据和公共基础，P1 为核心玩法一致，P2 为内容/表现与周边系统，P3 为完整发布范围。
优先级只决定先后；约定范围内的项目最终都需完成。手机触控继续遵循当前暂缓安排。

## 基线核对结论

* 现有权威战斗、账号存档、装备成长、制作和特殊流程均作为扩展基础，避免推倒重做。
* `CombatInstance` 仍包含 `strike/nova/rally` 路径及暂定效果；技能目录的真实性不能替代逐技能移植。
* `M3_STATUS.md` 仍记录穿透应用 Inferred、AI 条件近似、召唤属性暂定、环形刷怪点、离线用当前阶层替代检查点历史等差异。
* 据 [M0 素材审计](M0_ASSET_AUDIT.md)，原版使用 3D 环境和头像 token；**不安排为角色增加骨骼模型**。
  应恢复的是原版材质、特效、声音、相机与界面。新增骨骼角色属于额外改编。
* 旧计划和状态文档存在历史值（例如原型技能、离线上限），须绑定版本，避免新旧报告互相覆盖。
* 组队、交易、排行榜、赛季等具体范围需按选定原版版本核对，不预设所有列举功能都存在或行为相同。

## 推荐执行批次

1. **证据与首批真实技能**：先做 B01–B05、C04，再围绕 C05 实现 B06/C01–C03；交付四个有原版对照的技能，确认架构能承载其差异。
2. **全部技能与装备规则**：推进 C06–C08、E01–E05；同时按恢复出的技能补 V03，避免后端完成而网页看不见。
3. **完整世界与专属单位**：W01–W07、P01–P04；地图和资源按实际世界清单展开，不只增加一两张地图。
4. **交互与视听一致**：V01–V03、U01–U03 补齐覆盖；资源清点与 UI 规格核对可以提前做。
5. **在线范围与发布**：O01 提前核对，S01 在跨账户事务前完成；再按原版范围做 O02–O04、S02–S03，最后 A01。S04 保持暂缓。

这是依赖顺序，不是工期承诺。各批次验收后按剩余差异重新估量工作量。
