## 前置条件（必读，2026-10-03 更新：官方服务器已关闭）

1. **客户端**：官方未补丁 1.9.3（`nord.xapk`），**不要**用 v8–v16 补丁客户端。
   原因：补丁版的 10x 经验 / 5x 掉落会污染掉落与经验样本。
2. **服务器**：我们的私服（Lightsail）。官方服务器已关闭，无法再连官方服。
   有效性依据：反汇编已确认掉落掷骰（`ItemGenerator.CreateRandomItem` + `Droprates.json`）
   与怪物属性（`Monster.CalculateAttributes`）都在客户端完成，服务端只记账 replay，
   因此"私服 + 官方未补丁客户端"的行为样本与官方服等价。
   唯一例外：与私服特有逻辑相关的样本（如私服才有的 NPC 价格）不作为原版证据。
3. **记录工具**：手机录屏（开伤害数字显示）；属性面板截图（每次采集前截一张）。
4. **变量控制**：一次只动一个变量；采集前记录 MF、武器伤害、相关被动/精通状态。

## 样本 S-FORK-1：分叉行为

- **目的**：`Fork` 被动（Hunter，id 142）的真实弹体行为。
- **前置**：Hunter 角色，点出 Fork 被动；主动技能用 Multishot。
- **步骤**：
  1. 找 3 只以上聚集的怪，站好位置，录屏开始。
  2. 对中间的怪打一发 Multishot，观察箭的飞行轨迹。
  3. 重复 5 次。
- **记录**：每次分叉出的箭支数；分叉箭是否命中其他怪；主目标/分叉目标的伤害数字各记 3 组。
- **判定要点**：分叉是"命中后分裂"还是"发射时多支"；分叉伤害是否衰减。

## 样本 S-BUFF-1：毒是刷新还是叠加

- **目的**：毒 Debuff 的叠加语义（网页当前是"最高 DPS 加刷新"近似，见 D07）。
- **前置**：有毒伤来源（DeadlyPoison 被动或 PoisonCloud）；找一只血厚的怪（精英/Boss）。
- **步骤**：
  1. 上一次毒，记录跳伤数字（记 3 跳）和持续秒数。
  2. 等 2 秒，再上一次毒，记录跳伤数字是否变大。
  3. 对比：跳伤不变 = 刷新；跳伤变大 = 叠加。
- **记录**：两次的跳伤数字、持续时间；附录屏。

## 样本 S-BUFF-2：毒的清除条件

- **目的**：毒在目标死亡/驱散/换图后是否残留。
- **步骤**：
  1. 给怪上毒，在毒还没跳完时击杀它——观察毒是否跳到附近的怪身上。
  2. 上毒后立即换地图（进出传送门），回来观察怪身上是否还有毒。
- **记录**：两种情况的结果（有/无），附录屏。

## 样本 S-DROP-1：掉落分布统计

- **目的**：掉落件数/稀有度的条件分布（E02；不要求逐次一致，比较分布与边界）。
- **前置**：MF 尽量归零（脱掉 MF 装备，截图属性面板）；固定刷一种怪、固定世界阶层。
- **步骤**：连续击杀 50 只，记录每只的掉落：件数 + 每件稀有度（白/蓝/黄/暗金）。
- **记录模板**（文本即可）：
  ```
  MF=0, 世界Tier=5, 怪=Bat, 武器=白板
  1: 0件
  2: 2件 蓝,白
  ...
  汇总: 50杀, 共掉落N件, 白n1/蓝n2/黄n3/暗金n4
  ```
- **注意**：中途不要换装、不要升级（升级可能改变掉落表）。

## 样本 S-SCALE-1：怪物缩放

- **目的**：同种怪在不同阶层的血量/伤害缩放（W01）。
- **前置**：脱装备只拿白板武器（固定自身输出），截图属性面板。
- **步骤**：在 Tier 1/5/10 分别找同种怪（如 Bat），记录：自己打它一下的伤害数字；它打一下掉你多少血；击杀用时。
- **记录**：`Tier=1: 我方伤害=xx, 受到伤害=xx, 击杀=xx秒`，三个阶层各 3 只怪。

## 样本 S-MAP-1：地图生成

- **目的**：同一世界的地形/刷怪点是否随机（W04）。
- **步骤**：同一世界进出 3 次，每次截小地图全图。
- **记录**：3 张截图 + 地形是否相同（是/否）+ 刷怪点位置是否相同。
